Local controller · Experimental build 0.1.0

Jev × Factorio

Give Jev the mission of launching a rocket. Let it keep choosing actions, building and researching until you stop it or the game confirms a launch.

Live connection verified on Factorio 2.0.77. Autonomous rocket launch remains experimental.

Open the test world

Close any existing Factorio test host, then double-click Play-Test-World.cmd. It opens a separate peaceful world and prefills the controller’s local connection.

Start.cmd opens only the controller, idle.

Choose Offline Demo to see sample decisions. It uses no API key, network, or game. Its decisions are simulated.

What it can control

Navigate, mine, handcraft, build, configure and feed machines, select research, connect fluids, and launch a ready rocket.

Jev chooses one task, then the controller stays with it until it finishes or is blocked. Destinations stay fixed, mining gathers a batch, and crafting waits for its output before the next decision.

Start the rocket mission

  1. Enter your TypeSafe API key in the controller and click Save API key below the field. The key is encrypted for your Windows account and loads automatically next time. Forget key removes it.
  2. Click Rocket mission. It selects the rocket goal and autonomous recovery. Request and minute limits of 0 mean continuous running; enter finite limits if desired.
  3. Click Jev: OFF (click to enable) at the top left of Factorio.
  4. Within 60 game seconds, tick Execute actions in the controller and click Preview / Start.

Leave both programs open. Continuous mode makes ongoing requests to your paid TypeSafe API account. It stops on a verified rocket launch, manual Stop, a configured limit, or an unrecoverable error.

Continue without a time limit

The default goal is to build a factory, research the silo, and launch a rocket.

Autonomous mode retries temporary API errors, uses research milestones, and continues past uncertainty. Save the game manually before closing; do not rely on the host's autosave setting.

The log shows the current task and confirms completion. Continuing the same task makes no additional Jev requests. A request cap lets its last task finish; STOP and the time limit can still interrupt it.

Stop at any time

Click Jev: ON in Factorio to disarm immediately, or STOP in the controller. Movement, mining and navigation expire within 3 game seconds. Factory production can continue normally.

What has actually been verified

Jev successfully mined coal in the real game. The game bridge, saving, several advanced machine APIs and automated recovery tests have been checked. See VALIDATION.md for exact results.

The project failed to achieve its goal. Jev repeatedly cycled between tasks instead of building a productive factory or advancing research. This is the earlier Jev-controlled version, without the later scripted factory planner. There is no combat or Space Age mission support.
